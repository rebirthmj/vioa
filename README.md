# VIOA — AI 기반 얼굴 구조 분석 플랫폼

> K-뷰티 시대를 위한 맞춤형 얼굴 구조 분석 서비스

---

## 개요

VIOA는 의료관광을 위한 객관적·데이터 기반 얼굴 구조 분석 AI 플랫폼입니다.

복잡한 얼굴 구조를 실질적인 인사이트로 전환합니다.  

---

## 시장

- **K-뷰티 & 의료관광** — 연간 외국인 환자 120만 명 이상
- **성형외과·피부과 SaaS** — 병원·클리닉 대상 B2B 
- **B2C 앱** — 일반 소비자용 셀프 분석 서비스
- **B2C 앱** — 일반 소비자용 임대 및 분양 판매

---

## 기술

- AI 기반 얼굴 랜드마크 분석
- 독자적 구조 모델링 (특허출원 중)
- 프라이버시 보호 비식별 데이터 아키텍처
